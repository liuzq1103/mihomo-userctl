# Agent 安装指引

本地安装包请直接复制 [完整本地安装 prompt](agent-local-install-prompt.md)，默认来源 `/mnt/nas/public/software`。默认完整新装到控制器、可信核心与初始化，不自动启动；只有用户明确要求时才仅装控制器。

先阅读 [INSTALL.md](../../INSTALL.md)、[初始化](setup.md)、[安全](security.md) 和 [验证](first-run.md)。先只读审阅 Linux/Python、已有核心/配置、用户作用域、XDG 路径及网络条件。不打印私有文件，不把凭据放进参数。

安装前确认核心和网络条件。已有 manager 保留，不重复初始化、不主动 core install（可能重启运行时）。新装优先复用可信核心；缺失且允许联网时，x86_64 默认显式安装 v1.19.32，再 init 一次并 config validate，无需用户另选版本。内置摘要只覆盖 amd64-compatible，其他架构提前准备对应摘要或可信核心。严格离线缺材料时在安装前报告；本地来源不等于严格离线。

核验发行版及依赖后安装，按上述分支完成核心与初始化。复用保留已有数据。订阅先 preview，只展示脱敏摘要、ID 和候选 SHA256，在用户授权内 apply，需要时明确重启 Mihomo。按私有文件契约添加规则并只读检查，不恢复退役生命周期命令或 Shell hook。

遵守已有用户授权；只为缺失输入或超出范围的破坏操作询问，先完成可逆准备。不隐式 sudo、不改启动文件、不操作第三方服务或 TUN。私有导出接入文件。按实际证据记录 PASS/FAIL/UNVERIFIED，提供脱敏变更和回滚路径。控制器、核心、初始化分别验收；默认未启动，运行态与远端路由为 UNVERIFIED。本地代理成功不证明真实应用走远端节点。第三方安装器使用 [整个 Shell 的代理环境](first-run.md#通过代理安装第三方-cli)，优先先下载审阅后执行，不能只包裹管道左侧。已有安装按 [升级说明](update.md) 处理。
