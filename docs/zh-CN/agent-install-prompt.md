# Agent 安装指引

先阅读 [INSTALL.md](../../INSTALL.md)、[初始化](setup.md)、[安全](security.md) 和 [验证](first-run.md)。先只读审阅 Linux/Python、已有核心/配置、用户作用域、XDG 路径及网络条件。不打印私有文件，不把凭据放进参数。

核验发行版及依赖后安装，使用可信核心初始化，或显式安装固定且已核验摘要的核心。复用保留已有数据。订阅先 preview，只展示脱敏摘要、ID 和候选 SHA256，在用户授权内 apply，需要时明确重启 Mihomo。按私有文件契约添加规则并只读检查，不恢复退役生命周期命令或 Shell hook。

遵守已有用户授权；只为缺失输入或超出范围的破坏操作询问，先完成可逆准备。不隐式 sudo、不改启动文件、不操作第三方服务或 TUN。私有导出接入文件。按实际证据记录 PASS/FAIL/UNVERIFIED，提供脱敏变更和回滚路径。本地代理成功不证明真实应用走远端节点。已有安装按 [升级说明](update.md) 处理。
