# SSH 终端界面

完整包内置 Textual，直接运行 `mihomoctl` 或 `mihomoctl tui`，无需额外安装。每人使用独立 Linux 账号及代理实例，不需要 Web 或端口转发。

## 首次使用

1. 界面检查现有配置；新用户自动准备包内核验后的核心及私有配置，不重复初始化已有 manager。
2. 在订阅页粘贴 HTTPS URL（默认隐藏），也可选择 YAML 文件。无需手动建立 URL 文件。
3. 默认简单模式建立一个 Proxy 手动选择组；完整策略模式导入订阅分组和规则。已有自定义规则在简单导入时保留。
4. 预览节点及变更，确认“保存并启动”。启动失败会尝试恢复本次操作前的配置和运行状态。
5. 在节点页搜索、测速、选择节点。选择在重启后保留；切换节点不强制关闭已有连接。

## 常用入口

```bash
mihomoctl
mihomoctl tui --engine plain
mihomoctl exec -- codex
mihomoctl direct -- codex
mihomoctl --help
```

首页、节点、订阅及“使用代理”为主要入口，其他功能在“更多”。方向键和 Tab 移动，Enter 确认，q 退出。界面退出后当前用户的核心继续运行，普通 Shell 环境保持原状。编号菜单支持基本订阅和节点操作；完整界面支持搜索及单点/批量测速。

订阅请求在后台执行，Esc 可取消，取消可能等待当前有超时限制的网络读结束。窗口过小时使用编号菜单。JSON、管道、帮助不启动交互界面。

## 键盘操作与测速结果

| 按键 | 操作 |
| --- | --- |
| Tab / 方向键 / Enter | 移动焦点、浏览、确认 |
| `/`、`[` / `]` | 搜索节点、上一组 / 下一组 |
| `t` / `T` | 测试当前节点 / 批量测速 |
| `r`、`p`、`s` | 刷新、暂停观测、调整排序 |
| `v`、`?`、`:` | 结果详情、帮助、命令输入 |
| Esc、`q` / Ctrl+C | 取消工作、退出界面 |

快捷键在文本输入框未占用对应按键时生效。延迟测试通过该节点访问探测目标，不是带宽测试，也不代表真实业务请求成功。`unknown-node` 和 `node-not-in-core` 表示核心表中找不到准确名称；`node-unreachable` 表示探测失败，`delay-timeout` 表示超时。见 [测速排障](troubleshooting.md)。

“更多”保留连接、提供商、规则、日志、诊断及运行时控制。命令输入支持 `subscribe /absolute/private/subscription.yaml`，探测设置如 `health-check provider "ProviderName" --preset resilient`；Selector 需对其背后的 provider 配置探测。审阅预览后保存，按提示显式重启。终端订阅的“保存并启动”会在同一可恢复操作中完成两步；下面的高级 CLI preview/apply 不会自动启动。

## 当前状态与失败恢复

只保留当前软件、核心和配置，不提供恢复备份按钮或历史回滚。未完成事务的临时材料在成功或恢复完成后删除；恢复失败时保留必要材料并显示错误。订阅连接失败、格式错误、核心未就绪时可修正后重试。软件包离线可用不等于订阅或提供商资源离线可用。

## 高级操作

脚本继续使用 `subscription preview --url-file` / `--source-file` 及 `subscription apply`；这些命令保存后仍需显式启动或重启。高级配置、完整路由、健康检查、接入和 systemd 入口继续保留。源码安装的 extra/wheelhouse 仅是兼容路径，普通用户选择完整包。

更新前关闭本账号其他会话中的 mihomoctl 界面，再执行更新；程序会在切换前检查，避免删除仍在使用的界面代码。关闭界面不会停止核心。取消的预览会清理，下次进入界面或执行订阅操作时清理超过 24 小时的预览；订阅原文在内存中解析。
