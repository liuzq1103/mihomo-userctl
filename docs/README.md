本项目面向 Linux 用户级服务；仓库不分发、不安装 PC Clash/FlClash 规则。
v0.8 提供可选的 `mihomoctl override --script` 与 `--flclash-compat`，只用于适配
用户自己审阅过的本地脚本，不属于安装流程。
This project manages Linux user services and ships no PC Clash/FlClash rules.
v0.8 adds the optional `mihomoctl override --script` and `--flclash-compat` entry
points; they adapt a local script the user reviewed and are not part of installation.
