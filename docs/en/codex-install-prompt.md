# Terminal installation agent prompt

Install the complete mihomoctl bundle for the current independent Linux account. Verify provenance, checksums, architecture and Ubuntu compatibility, then copy into an owned private directory. Use the bundle's `./install.sh --user`. Do not create a venv, run pip, separately install Textual or require port forwarding.

Preserve existing managers and active cores. For a new user, run `mihomoctl` and use its terminal wizard to prepare the included core, privately enter a subscription, review changes and obtain the user's confirmation before saving and starting. Then select a node. Explain unreachable subscription endpoints and support local YAML. Never put subscription URLs or secrets in arguments, logs or reports.

Default to user/process without sudo/systemd, shell startup edits or third-party service actions. Keep only current code, core and configuration. No historical backups or rollback. Recover unfinished transactions; preserve necessary temporary material on recovery failure. Verify version/help after installation; actual node connectivity requires an observed request.

See [installation](../../INSTALL.md) and the [console guide](console.md).
